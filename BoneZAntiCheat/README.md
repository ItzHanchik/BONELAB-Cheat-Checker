# BoneZ AntiCheat Checker 2.8

Публичный исходный код и подписанные релизы: https://github.com/irembo337/BONELAB-Cheat-Checker

Версия 2.8 выпускается как `Checker.exe` / `Checker.dll`, использует полностью
чёрную пользовательскую рамку без белой системной полосы и только автоматическое обнаружение Discord Data Package,
без кнопки ручного выбора и drag-and-drop. Она также включает аудит DLL в каталогах
`Mods`, `Plugins`, `UserData` и во всей папке установки BONELAB. DLL из известных
модовых каталогов включаются всегда. DLL из остальных каталогов игры попадают в
evidence-ZIP и декомпиляцию только при совпадении точного SHA-256, имени, пути или
набора статических сигнатур; обычные библиотеки игры пропускаются. Проверка не
загружает и не исполняет найденные сборки.
Управляемые .NET-сборки также декомпилируются в C# библиотекой ILSpy; нативные и
повреждённые файлы остаются в ZIP и отмечаются в `audit.log`. Каждая DLL получает
отдельную папку `assemblies/NNN-name-id/` с `original/`, `source/` и `info.txt`.
`source/` содержит проект ILSpy с раздельными файлами классов, ресурсами и `.csproj`,
а не один общий `*.decompiled.cs`. В архив также добавляются
JSON/TXT-отчёты, а после GUI-проверки ZIP автоматически открывается в Проводнике.

RepUtils v5 и no-license определяются по точному SHA-256, имени файла, ссылкам в
логах и набору статических индикаторов, поэтому простое переименование DLL не
скрывает известную сборку от проверки.

Дополнительные пороговые правила ищут группы независимых IL-строк, характерных для
God Mode, Stat Changer, Aim manipulation и Freecam. Checker возвращает каждую
совпавшую категорию, даже если одна DLL содержит сразу несколько функций. Одно
общее слово не считается доказательством: для `DETECTED` нужны минимум три
индикатора одной категории.

Локальный Windows-чекер клиента BONELAB. Windows всегда запрашивает права
администратора через UAC. После подтверждения запуск проверяет все доступные
фиксированные диски, активные процессы, автозапуск и только локальные артефакты
Discord. Файлы не удаляются, не запускаются и никуда не загружаются.

Дополнительно проверяются локальные Steam-аккаунты из официального
`config/loginusers.vdf`: SteamID64 сравниваются с SHA-256 fingerprint-снимком
постоянных банов проекта BoneZ. Список не содержит имён игроков или открытых SteamID.

## Интерфейс

- полностью чёрное минималистичное окно без старых карточек и выбора области;
- центральная кнопка `CHECK THIS PC`;
- во время проверки остаются `by iremb0`, анимированный круг, одна честная
  неопределённая полоса прогресса и небольшая кнопка Discord;
- отдельный экран результата и отдельное окно подробного отчёта.
- живые этап, время и счётчики просмотренных/проверенных файлов и каталогов;
- нажатие на анимированный круг безопасно отменяет текущую проверку.
- Checker автоматически ищет официальный Discord Data Package в `Downloads`,
  `Desktop`, `Documents` и соответствующих папках OneDrive. ZIP или распакованная
  папка подтверждается по разделам `messages` и минимум двум официальным разделам
  (`account`, `activity`, `servers` и др.), а не только по имени;
- ручной выбор не требуется: официальный пакет обнаруживается и проверяется
  автоматически во время каждого запуска проверки;
- нижняя кнопка использует неискажённую белую геометрию официального Discord Symbol
  из `https://discord.com/branding` с сохранённым соотношением сторон;

## Архитектура

- `Scanner/FileSystem` — безопасный обход каталогов без перехода по reparse points;
- `Scanner/Hashes` — SHA-256 после быстрого фильтра по расположению, имени и известному размеру;
- `Scanner/Processes` — активные процессы;
- `Scanner/Startup` — системный и пользовательский автозапуск;
- `Scanner/Discord` — локальные имена/пути/хэши без чтения токенов; официальный
  Data Package безопасно обнаруживается по структуре в стандартных пользовательских
  папках, после чего сообщения и названия каналов читаются только внутри него;
- `Scanner/Steam` — локальные Steam login records и project-ban fingerprints;
- `Scanner/Logs` — ограниченное чтение BONELAB `Player.log`/`Player-prev.log`,
  MelonLoader/Fusion/ReShade-журналов и поиск известных сигнатур без копирования строк в отчёт;
- `Scanner/Mods` — поиск DLL во всей Steam-установке BONELAB, обязательный аудит
  модовых каталогов и сигнатурный отбор подозрительных DLL из остальных папок;
- `Scanner/Signatures` — расширяемая база `signatures/*.json`;
- `Scanner/Reports` — подробные JSON и TXT в `%LOCALAPPDATA%\BoneZAntiCheat\Reports`.

`DETECTED` выдаётся только при точном SHA-256 или пороговом совпадении известных
статических признаков. Все совпавшие семейства показываются отдельно. Имя файла,
путь или имя процесса сами по себе дают только `SUSPICIOUS`.

## Сборка

```powershell
dotnet publish BoneZAntiCheat/BoneZAntiCheat.csproj -c Release -r win-x64 --self-contained true -o artifacts/Checker
```

### Authenticode-подпись

Для выпуска с сертификатом Code Signing используйте скрипт:

```powershell
.\scripts\Publish-BoneZAntiCheatSigned.ps1 -CertificateThumbprint <SHA1 thumbprint>
```

Он создаёт self-contained сборку, подписывает `Checker.exe` и
`Checker.dll` алгоритмом SHA-256, добавляет доверенную временную метку,
проверяет обе подписи через Windows SDK и только после этого создаёт ZIP.
Приватный ключ и PFX в проект или архив не копируются.

Самоподписанный сертификат считается доверенным только на компьютерах, где он
явно установлен. Для устранения предупреждений SmartScreen у других пользователей
нужен публично доверенный OV/EV Code Signing сертификат или Microsoft Trusted
Signing; одна подпись не гарантирует отсутствие эвристического срабатывания
антивируса.

## Ограничения

Неизвестный, зашифрованный или серьёзно переработанный чит может не совпасть с
локальной базой. Steam-ban snapshot обновляется вместе с новой сборкой Checker и
не является онлайн-доступом к панели сервера. Даже с правами администратора Windows может блокировать отдельные
системные файлы; они отмечаются как ошибки доступа. Проверка Discord намеренно не
читает активную сессию, токены или приватные базы клиента. Она читает только
структурно подтверждённый Data Package в стандартных пользовательских папках.
Весь ПК обходится по метаданным, а полное статическое чтение
ограничено пользовательскими, временными, BONELAB/Mods/MelonLoader-каталогами и
файлами, прошедшими сигнатурный префильтр. Официальный Discord Data Package обычно
содержит отправленные владельцем сообщения; полученные сообщения проверяются только
если экспорт действительно их содержит. Discord evidence
всегда помечается `SUSPICIOUS`, а не автоматически доказывает использование чита.
Чекер не заменяет серверную проверку поведения. Декомпилированный проект содержит
весь доступный ILSpy C# и ресурсы сборки, но это восстановленный код: оригинальные
комментарии, локальные имена и точное форматирование из DLL получить невозможно.
Нативные DLL нельзя восстановить в C#: они сохраняются как оригинал с причиной в
`info.txt`. Неизвестная DLL вне модового каталога без совпадения с текущей базой
сигнатур считается обычной игровой библиотекой и не декомпилируется.
Названия методов можно переименовать или зашифровать, поэтому статическая сигнатура
не гарантирует обнаружение каждой реализации God Mode/Stat Changer/Aim/Freecam;
серверный поведенческий контроль остаётся отдельным обязательным уровнем защиты.
